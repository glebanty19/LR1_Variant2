# ЛР1 — Варіант 2: оцінювання пошкоджень будівель в Ірпені

Навчальний проєкт для первинного огляду знімка та формалізації задачі оцінювання
пошкоджень будівель і завалів житлового кварталу м. Ірпінь.

## Структура

```text
lab1/
├── .gitignore
├── README.md
├── requirements.txt
├── passport.yaml
├── inspect_scene.py
├── aoi.geojson
├── irpin_sentinel2_20220415.tif
├── scene_preview.png

├── histograms.png          # створюється скриптом
├── LR1_Variant2_Final.docx

```

`LR1_Variant2_Final.docx` — виправлена копія звіту; початковий DOCX залишився
локально без змін і до репозиторію не додається. `main.py` — початковий шаблон IDE; для огляду знімка використовуйте
`inspect_scene.py`.

## Приклад знімка

`irpin_sentinel2_20220415.tif` — GeoTIFF-вирізка трьох каналів Sentinel-2 L2A
(B04/B03/B02) для приблизної AOI з `aoi.geojson`, дата зйомки 15.04.2022.
Джерело: [Microsoft Planetary Computer, Sentinel-2 L2A](https://planetarycomputer.microsoft.com/dataset/sentinel-2-l2a);
STAC item `S2B_MSIL2A_20220415T090549_R050_T36UUB_20240617T181011`.
Дані Sentinel надаються за умовами [Copernicus Sentinel Data Legal Notice](https://sentinel.esa.int/documents/247904/690755/Sentinel_Data_Legal_Notice).

Вирізка має геоприв'язку й метадані знімання, але Sentinel-2 має роздільність
близько 10 м/піксель. Вона не дає надійно вимірювати чи класифікувати окремі
будівлі або завали; використовуйте її лише для перевірки скрипта та скринінгу.

## Встановлення та запуск

```bash
python -m pip install -r requirements.txt
python inspect_scene.py irpin_sentinel2_20220415.tif --rgb 1 2 3
```

Для іншого Sentinel-2 GeoTIFF із каналами 4, 3 і 2:

```bash
python inspect_scene.py scene.tif --rgb 4 3 2 --objects "малий будинок=6" "купа завалу=3" "будівля 15м=15"
```

Для PNG-чіпа без геоприв'язки вкажіть розмір пікселя:

```bash
python inspect_scene.py chip.png --gsd 0.5 --objects "будинок=12" "завал=6"
```

Скрипт створює в поточній директорії `scene_report.txt` і `histograms.png`.
`scene_preview.png` — RGB-візуалізація цієї AOI.
Для GeoTIFF із проєктованою CRS GSD береться з розміру пікселя та одиниць CRS;
для географічної CRS розрахунок приблизний. Параметр `--gsd` задає однаковий
розмір пікселя по обох осях і має використовуватися для незареєстрованих зображень.

## Дані й обмеження

Завантажте знімок, на який маєте право використання, і збережіть його локально;
великі знімки та дані з обмеженнями ліцензії не додавайте до репозиторію без
перевірки умов. Sentinel-2 із каналами 4/3/2 має роздільність 10 м і не підходить
для надійного вимірювання окремих невеликих будівель. Координати `aoi.geojson`
приблизні — перевірте їх у QGIS. Звіт та гістограма залежать від обраного знімка
і самі по собі не підтверджують точність класифікації чи оцінки пошкоджень.

Репозиторій проєкту: https://github.com/glebanty19/LR1_Variant2. Перед здачею уточніть межі AOI та за потреби заповніть поля кафедри й викладача у звіті.
